# รายจ่ายของฉัน (my-expense)

แอปบันทึกรายจ่ายที่**อ่านใบเสร็จจากรูปในเครื่องให้อัตโนมัติ** — เปิดแกลเลอรี
เลือกรูปใบเสร็จ แล้วแอปจะดึงยอดเงิน ชื่อร้าน วันที่ และเดาหมวดหมู่ให้

เป็น PWA: เปิดจากเบราว์เซอร์ กด "เพิ่มไปยังหน้าจอโฮม" แล้วใช้เหมือนแอปทั่วไป
ไม่ต้องลงผ่าน App Store

## ข้อมูลอยู่ในเครื่องทั้งหมด

ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ไม่มีการอัปโหลด

- รายการและรูปใบเสร็จเก็บใน **IndexedDB** ของเบราว์เซอร์
- การอ่านใบเสร็จ (OCR) รันด้วย **WebAssembly ในเครื่อง** ไม่ได้ส่งรูปไปไหน
- ไฟล์ของ OCR ทั้งหมด (worker, wasm core, ข้อมูลภาษาไทย/อังกฤษ) เสิร์ฟจาก
  origin ของแอปเอง ไม่แตะ CDN ภายนอก → ใช้งานแบบออฟไลน์ได้เต็มรูปแบบ

> เพราะข้อมูลอยู่ในเครื่อง การล้างข้อมูลเว็บไซต์หรือถอนแอปจะลบรายการทั้งหมด

## การเข้าถึงแกลเลอรี

แอปเข้าถึงรูปผ่าน `<input type="file">` ซึ่งเป็นทางเดียวที่เว็บทำได้ — ระบบปฏิบัติการ
เป็นคนเปิดหน้าเลือกรูป และส่งกลับมาเฉพาะไฟล์ที่ผู้ใช้เลือกเท่านั้น

- **ถ่ายรูป** — `capture="environment"` เปิดกล้องหลังโดยตรง
- **เลือกจากแกลเลอรี** — `multiple` เลือกได้หลายรูปพร้อมกัน แล้วแอปจะไล่อ่านทีละใบ

แปลว่าแอปไม่สามารถไล่ดูรูปในเครื่องเองได้ ต้องให้ผู้ใช้เลือกเสมอ ซึ่งเป็นพฤติกรรม
ที่ถูกต้องและไม่ต้องขอ permission ใด ๆ ล่วงหน้า

## เริ่มใช้งาน

```bash
npm install          # ดึง OCR core + ข้อมูลภาษาเข้ามาด้วย
npm run dev          # เปิดที่ http://localhost:5173
npm run build        # สร้างไฟล์ production ที่ dist/
npm run preview      # ลองรันไฟล์ที่ build แล้ว
```

ทดสอบบนมือถือ: รัน `npm run dev -- --host` แล้วเปิด URL บนเครื่องที่อยู่วง LAN
เดียวกัน (กล้องและ service worker ต้องการ HTTPS หรือ `localhost`)

### คำสั่งอื่น

```bash
npm run lint               # oxlint
npm run validate:palette   # ตรวจสีหมวดหมู่ (ดูหัวข้อ Design system)
npm run icons              # สร้างไอคอน PWA ใหม่จาก scripts/gen-icons.mjs
```

## โครงสร้าง

```
src/
  index.css                design token ทั้งหมด (สี ระยะ เงา light/dark)
  types.ts                 รูปแบบข้อมูล Expense / ParsedReceipt
  lib/
    ocr.ts                 จัดการ tesseract worker + timeout + fallback
    image.ts               ย่อรูปและแก้การหมุนตาม EXIF ก่อนเข้า OCR
    parseReceipt.ts        ดึงยอด/วันที่/ชื่อร้านจากข้อความที่ OCR ได้
    categories.ts          หมวดหมู่และคำใบ้สำหรับเดาหมวด
    db.ts                  IndexedDB (รายการ + รูปใบเสร็จแยก store)
    store.ts               external store สำหรับ useSyncExternalStore
    format.ts              จัดรูปแบบเงินบาทและวันที่ไทย
  components/              UI ทั้งหมด (ui/ = primitive ที่ใช้ซ้ำ)
scripts/
  sync-ocr-assets.mjs      คัดลอกไฟล์ OCR จาก node_modules -> public/
  validate-palette.mjs     ตรวจ palette ตามเกณฑ์ data-viz
  gen-icons.mjs            สร้างไอคอน PNG โดยไม่ต้องใช้เครื่องมือภายนอก
```

## การอ่านใบเสร็จ

1. ย่อรูปให้ด้านยาวสุด 1600px และหมุนตาม EXIF (`lib/image.ts`)
2. ส่งเข้า Tesseract LSTM ด้วยภาษา `tha+eng` (`lib/ocr.ts`)
3. แยกข้อมูลจากข้อความที่ได้ (`lib/parseReceipt.ts`):
   - **ยอดเงิน** — ให้น้ำหนักคำว่า `รวมทั้งสิ้น`/`ยอดสุทธิ` มากกว่า `ยอดรวม`
     มากกว่า `รวม` และข้ามบรรทัด VAT / ส่วนลด / เงินสด / เงินทอน
     รองรับกรณีเครื่องพิมพ์ตัดบรรทัดจนตัวเลขตกไปบรรทัดถัดไป
   - **วันที่** — รองรับ `dd/mm/yyyy`, `yyyy-mm-dd`, ชื่อเดือนไทย/อังกฤษ และ
     แปลง พ.ศ. เป็น ค.ศ. ให้ พร้อมปฏิเสธวันที่ที่เป็นไปไม่ได้หรืออยู่ในอนาคต
   - **ชื่อร้าน** — เอาจากบรรทัดบน ๆ ที่ไม่ได้มีแต่ตัวเลข (เลขภาษี เบอร์โทร)
4. คำนวณค่าความมั่นใจ ถ้าต่ำกว่า 0.5 จะขึ้นเตือนให้ตรวจตัวเลขอีกครั้ง

ถ้า OCR ล้มเหลวหรือค้าง (มี timeout กำกับ) แอปจะเก็บรูปไว้และให้กรอกเอง
ไม่ทิ้งรูปที่ผู้ใช้เลือกมาแล้ว

## Design system

สีและค่าต่าง ๆ อยู่ที่ `src/index.css` ที่เดียว แบ่งเป็นสองชั้น:

- **token ดิบ** — `--color-brand-*`, `--color-cat-*` (ค่าคงที่)
- **token เชิงความหมาย** — `--surface-*`, `--text-*`, `--border-*`
  ซึ่งนิยามใหม่ในโหมดมืด ทำให้คอมโพเนนต์ไม่ต้องรู้ว่าตอนนี้เป็นโหมดไหน

คอมโพเนนต์ใช้ค่าผ่าน utility ของ Tailwind (`bg-surface-raised`, `text-text-muted`)
ไม่มีการเขียนค่าสีดิบใน TSX

สีประจำหมวดหมู่ผ่านการค้นหาค่าด้วยเครื่องมือตรวจ แล้ว**ตรวจซ้ำได้**:

```bash
npm run validate:palette
```

เกณฑ์ที่ตรวจคือช่วงความสว่าง, chroma ขั้นต่ำ, การแยกแยะสำหรับคนตาบอดสี
(protan/deutan/tritan), การแยกแยะสำหรับสายตาปกติ และคอนทราสต์กับพื้นหลัง —
ตรวจ **ทุกคู่สี** ทั้งโหมดสว่างและมืด เพราะกราฟเรียงตามยอดเงิน สีไหนก็มาอยู่
ติดกันได้ ถ้าจะแก้สีหมวดหมู่ ต้องรันคำสั่งนี้ให้ผ่านก่อน

ค่า ΔE ของคนตาบอดสีอยู่ในช่วง 6–8 ซึ่งยอมรับได้เฉพาะเมื่อมีตัวช่วยอื่นนอกจากสี —
ในแอปนี้ทุกแถบและทุกแถวมีทั้งอีโมจิและข้อความกำกับเสมอ สีจึงไม่ใช่สิ่งเดียวที่
บอกว่าเป็นหมวดไหน และหน้าสรุปยังสลับดูเป็นตารางได้ด้วย
