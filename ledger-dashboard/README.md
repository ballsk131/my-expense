# แดชบอร์ดสมุดบัญชีรายเดือน

หน้าเดียวจบ อ่านข้อมูลจาก `data.js` ที่วางไว้ข้าง ๆ กัน เปิดตรง ๆ ด้วย
`file://` ก็ทำงานได้ ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์

เผยแพร่เป็น Artifact ส่วนตัวที่ `https://claude.ai/artifact/Y5iWAcB692iA16v2NezvMT`
ซึ่งเป็นลิงก์ถาวร อย่าสร้างใหม่ ให้ publish ทับลิงก์เดิมเสมอ

## ทำไมไม่มี data.js ในรีโป

`data.js` คือสมุดบัญชีจริง มีชื่อร้าน ชื่อบุคคล และยอดเงินทุกรายการ
จึงตั้งใจไม่ commit และใส่ไว้ใน `.gitignore` แล้ว ฉบับจริงอยู่ใน
Artifact ข้างบน ดึงกลับมาได้ด้วย `Artifact` action `read` พร้อม
`path: "data.js"`

ไฟล์นี้ถูก commit ไว้เพื่อให้ตัวหน้าเว็บรอดจากการที่คอนเทนเนอร์ถูกล้าง
ส่วนข้อมูลให้ดึงจาก Artifact เสมอ

## โครงสร้าง

```
window.LEDGER = { meta: {...}, rows: [...] }
```

แต่ละแถว: `{d, cm, t, a, m, c, n, q}` โดย `d` คือวันที่จริง และ `cm` คือ
รอบบัญชี (25 ถึง 24) ซึ่งปกติคำนวณจาก `d` ได้ แต่ไม่เสมอไป — ถ้าวันที่ 25
ตรงวันหยุด ธนาคารจะตัดค่างวดก่อนหน้า ทำให้ `cm` ไม่ตรงกับ `d`
**ให้เชื่อ `cm` เสมอ**
